\section{分析题目要求}
\subsection{题目要求分析}
根据《<数据结构>综合性、设计性实验指导》的实验内容，本实验的研究对象为平衡二叉树（Balanced Binary Tree, AVLTree），基于基本的二叉树完成对平衡二叉树的增加、删除、修改、查询（后文会简称为增删改查）、遍历、统计等操作。
\begin{enumerate}
    \item {
          插入新节点。
          往二叉树中插入新节点，并且插入新节点之后要求左右平衡，
          要求形成平衡二叉树，并且维护好左右子树的平衡。
          }
    \item {
          递归遍历树。
          前序、中序、后序遍历二叉树 （递归）。
          平衡二叉树本质上也是二叉树，实现二叉树的前序遍历、中序遍历和后序遍历的递归算法。递归遍历能够直接体现二叉树本身的递归定义，可以帮助我们更好地理解二叉树结构和递归思想。
          }

    \item {
          非递归算法遍历树。
          前序、中序、后序遍历的非递归算法。
          由于递归遍历算法需要消耗大量系统栈资源，容易导致栈溢出。可以用自定义栈来模拟系统栈，从而实现对二叉树的遍历。
          }
    \item {
          层次遍历二叉树。
          实现二叉树的层次遍历，按照从上到下、从左到右的顺序访问该二叉树中的各个节点，本操作童谣需要借助栈。
          }
    \item {
          在二叉树中查找给定关键字。
          在该二叉树中查找指定关键字（key）的节点，函数返回值为成功1,失败0。
          }
    \item {
          交换各结点的左右子树。
          实现对二叉树所有节点的左右子树的交换操作，该操作需要遍历访问每个节点，通常使用递归方法，得到一颗镜像二叉树。
          }
    \item {
          求二叉树的深度。
          从根节点计算到高度最大的叶子结点，该功能可以利用递归，得到根节点的左右子树的高度，取较大值加上根节点本身的一层。
          }
    \item {
          叶子结点数。
          统计二叉树中的叶子结点，即没有左右子树的节点数量，该操作需要遍历所有节点，并判断是否符合要求、
          }
    \item {
          删除某结点。
          实现删除平衡二叉树中的指定节点，删除操作需要根据关键词查找目标节点，并根据该节点是否含有子树进行进一步操作，而且删除后需要维持平衡二叉树的结构。
          }
\end{enumerate}
综上所述，本实验不仅要求实现二叉树的基本操作，还要求分别使用递归、栈和队列等不同方法解决二叉树问题。通过本实验，可以进一步理解二叉树的存储方式、遍历过程以及树结构中查找、修改和统计等算法的设计思路。

\subsection{规范}
\subsection{程序设计规范}

由于本实验没有具体规定编程语言，本文采用 C++ 语言完成程序设计。C++ 支持面向对象程序设计，适合将平衡二叉树封装为一个类，将插入、删除、查找、遍历、统计等操作封装为成员函数。这样既可以提高程序结构的清晰度，也便于后续对各个功能进行测试和维护。

本程序以平衡二叉树 AVLTree 作为主要数据结构。树中每个结点保存关键字、父结点指针、左孩子指针、右孩子指针、平衡因子以及结点高度。程序通过这些信息维护二叉排序树性质和平衡二叉树性质。对外提供的主要功能包括插入新结点、递归遍历、非递归遍历、层次遍历、查找关键字、交换左右子树、求树的深度、统计叶子结点数以及删除指定结点。

\subsubsection{函数命名、参数与返回值规范}

为了使程序结构清晰，本文将平衡二叉树的基本操作封装为 AVLTree 类的成员函数。各函数的命名、参数和返回值如表 \ref{tab:funs} 所示。



\subsubsection{输入形式与输入范围}

本程序采用菜单交互的方式进行输入。用户首先输入一个整数作为菜单选项，程序根据该选项执行对应功能。当用户选择插入、查找或删除操作时，需要继续输入一个整数作为结点关键字。

输入内容主要包括以下几类：

\begin{enumerate}
    \item {
          菜单选项：输入整数表示要执行的功能，例如插入、删除、查找、遍历、统计等操作。
          }
    \item {
          插入结点：输入一个整数作为新结点的关键字。
          }
    \item 查找结点：输入一个整数作为待查找的关键字。
    \item 删除结点：输入一个整数作为待删除的关键字。
\end{enumerate}

关键字的数据类型为 int，因此输入范围应满足 C++ 中 int 类型的取值范围。为便于测试和观察树结构，实验测试时一般选取较小范围内的整数，例如 1 到 100 之间的整数。若输入的关键字已经存在，则插入失败；若查找或删除的关键字不存在，则返回失败结果。

\subsubsection{输出形式}

程序的输出主要包括操作结果和遍历结果两类。

对于插入、查找和删除操作，程序输出操作是否成功。例如，插入成功时输出插入成功，若插入重复关键字则输出插入失败；查找成功时输出查找成功，查找不到则输出查找失败；删除成功时输出删除成功，若目标结点不存在则输出删除失败。

对于遍历操作，程序输出一个整数序列。前序遍历、中序遍历、后序遍历和层次遍历均以 vector\textless{}int\textgreater{} 的形式保存结果，并按照访问顺序依次输出其中的关键字。对于求深度和统计叶子结点数操作，程序直接输出对应的整数结果。

因此，程序输出形式可以归纳如下：

\begin{enumerate}
    \item 插入、查找、删除等操作输出布尔结果或相应提示信息。
    \item 遍历操作输出关键字序列。
    \item 求深度操作输出二叉树的深度。
    \item 统计叶子结点数操作输出叶子结点总数。
    \item 交换左右子树操作输出镜像后的遍历结果，用于验证交换是否成功。
\end{enumerate}

\subsubsection{程序功能要求}

本程序最终需要实现一棵平衡二叉树的基本操作。具体来说，程序应能够完成以下功能：

\begin{enumerate}
    \item 能够向平衡二叉树中插入新结点，并在插入后维护平衡二叉树的结构。
    \item 能够分别使用递归方法完成前序遍历、中序遍历和后序遍历。
    \item 能够分别使用非递归方法完成前序遍历、中序遍历和后序遍历。
    \item 能够使用队列完成二叉树的层次遍历。
    \item 能够根据给定关键字在树中查找对应结点，并返回查找结果。
    \item 能够交换每个结点的左右子树，得到原二叉树的镜像结构。
    \item 能够计算二叉树的深度。
    \item 能够统计二叉树中的叶子结点数。
    \item 能够删除指定关键字对应的结点，并在删除后尽量保持平衡二叉树的结构。
\end{enumerate}

综上，程序不仅要完成普通二叉树的遍历和统计操作，还要体现平衡二叉树的特点，即在插入和删除过程中维护树的平衡性，使树的高度保持在较低水平，从而提高查找、插入和删除操作的效率。

\section{解题思路}
实验中我们采取链式存储结构，形成一棵链树，每个节点中保存
父节点指针、左孩子指针、右孩子指针、key、平衡因子（balance factor, BF）、树深度。

主要用到链表、栈、队列和动态数组。其中，链表用于存储树结点，栈用于实现非递归遍历，队列用于实现层次遍历，动态数组用于保存并返回遍历结果。

然后按照二叉排序树的性质寻找插入位置：如果待插入key小于当前结点的key，则继续进入左子树；若大于当前结点关键字，则继续进入右子树；若等于当前结点关键字，则说明该关键字已经存在，插入失败，返回false。

找到空位置后，新建结点并根据大小关系与其父节点进行连接。

由于插入新结点后可能破坏 AVL 树的平衡性，因此需要从新插入结点开始自下而上更新高度和BF，并在发现节点失衡的时候进行旋转操作。

插入操作的伪码如下：

\begin{lstlisting}
Insert(key):
    if root == nullptr{
        root = new Node(key)
        return true
    }
    curr = root
    parent = nullptr
    while curr != nullptr{
        parent = curr
            if key < curr->key:
                curr = curr->left
            else if key > curr->key:
                curr = curr->right
            else:
                return false
    }
    newNode = new Node(key)
    newNode->parent = parent
    if key < parent->key:
        parent->left = newNode
    else:
        parent->right = newNode
    /*
        从 newNode 开始向上更新高度和平衡因子
        若出现失衡，则根据 LL、RR、LR、RL 四种情况进行旋转
    */
    return true
\end{lstlisting}

\subsection{算法的效率分析和改进设想}

本实现中各主要操作的时间复杂度分析如下。

\subsubsection{旋转操作}

四种旋转（LL/RR/LR/RL）均只修改常数个指针，并在旋转后调用 \texttt{update\_height}。\texttt{update\_height} 直接读取左右孩子已存储的 \texttt{height} 字段取最大值，时间复杂度为 O(1)。因此单次旋转操作时间复杂度为 \textbf{O(1)}。

\subsubsection{插入操作}

插入分为两步：首先按二叉搜索树性质查找插入位置，时间复杂度 O(log n)；然后从新节点向上回溯至根，逐层调用 \texttt{update\_height} 更新高度与平衡因子，必要时执行旋转。回溯路径长度等于节点深度，最坏为 O(log n)，每步为 O(1)。故插入总时间复杂度为 \textbf{O(log n)}。

\subsubsection{删除操作}

删除同样包含查找目标节点（O(log n)）、删除节点（O(1) 或查找后继 O(log n)）以及向上回溯平衡（O(log n)）。总时间复杂度为 \textbf{O(log n)}。

\subsubsection{查找操作}

直接按二叉搜索树性质二分查找，时间复杂度为 \textbf{O(log n)}。

\subsubsection{遍历操作}

递归遍历、基于栈的非递归遍历、层次遍历均需访问每个节点恰好一次，时间复杂度均为 \textbf{O(n)}。空间复杂度：递归遍历 O(h)（系统栈），栈遍历 O(n)（显式栈），层次遍历 O(n)（队列），其中 h 为树高。

\subsubsection{统计与工具操作}

\texttt{count\_leaves()} 采用 BFS 遍历全树，时间复杂度 O(n)。\texttt{depth()} 直接返回根结点已维护的 \texttt{height} 字段，时间复杂度 O(1)。\texttt{mirror()} 递归交换所有左右子树，时间复杂度 O(n)。

\subsubsection{当前实现的可改进之处}

\begin{enumerate}
    \item \textbf{\texttt{depth()} 可优化为 O(1)}：当前 \texttt{depth()} 通过 \texttt{\_depth\_imp} 递归遍历整棵树计算深度，实际上根节点的 \texttt{height} 字段已正确维护了树的深度，直接返回 \texttt{root->height} 即可将 O(n) 降为 O(1)。
    \item \textbf{查找代码重复}：\texttt{search()} 与 \texttt{del()} 中都包含完全相同的二叉搜索树查找逻辑（按 key 比较沿左右子树下降），可抽取为私有辅助函数 \texttt{\_find\_node(key)} 以减少代码重复，提高可维护性。
    \item \textbf{附录代码与源文件不一致}：当前附录中 \texttt{rotate\_left\_right} 与 \texttt{rotate\_right\_left} 的实现存在错误（broken->right 和 broken->left 赋值错误），与源码 \texttt{insert.cpp} 不符，需同步修正。
    \item \textbf{遍历函数返回值风格统一}：部分遍历函数直接返回 \texttt{vector<int>}，而 \texttt{depth()} 和 \texttt{count\_leaves()} 返回 \texttt{unsigned}，接口风格可进一步统一。
\end{enumerate}

#include <AVLTree.h>
// LL-type的重新平衡，右旋操作，看那个csdn的图就很好写了
AVLTree::AVLNode AVLTree::rotate_right(const AVLTree::AVLNode &broken) {
    if (broken == nullptr || broken->left == nullptr) {
        return nullptr;
    }
    // 做一下保存操作
    AVLNode left = broken->left;
    AVLNode parent = broken->parent;

    // 右旋
    broken->left = left->right;
    if (broken->left) {
        broken->left->parent = broken;
    }
    left->right = broken;
    broken->parent = left;
    left->parent = parent;

    return left;
}

// RR-type 左旋
AVLTree::AVLNode AVLTree::rotate_left(const AVLTree::AVLNode &broken) {
    if (broken == nullptr || broken->right == nullptr) {
        return nullptr;
    }
    // 备份
    AVLNode r = broken->right;
    AVLNode parent = broken->parent;

    // 左旋操作
    broken->right = r->left;
    if (broken->right) {
        broken->right->parent = broken->right;
    }
    r->left = broken;
    broken->parent = r;
    r->parent = parent;
    return r;
}
// LR-type
AVLTree::AVLNode AVLTree::rotate_left_right(const AVLTree::AVLNode &broken) {
    if (broken == nullptr || broken->left == nullptr) {
        return nullptr;
    }
    broken->right = rotate_left(broken);
    return rotate_right(this->root);
}

// LR-type
AVLTree::AVLNode AVLTree::rotate_right_left(const AVLTree::AVLNode &broken) {
    if (broken == nullptr || broken->left == nullptr) {
        return nullptr;
    }
    broken->left = rotate_right(broken);
    return rotate_left(broken);
}

void AVLTree::re_BF(AVLNode &node) {
    while (node) {
        // 更新Balance Factor
        int left_height = node->left ? node->left->h : 0, right_height = node->right ? node->right->h : 0;
        node->bf = right_height - left_height;
        node->h = max(left_height, right_height) + 1;
        // 需要旋转
        if (node->bf < -1) { // 左子树过高
            if (node->left && node->left->bf <= 0) {
                node = rotate_right(node); // LL-type
            } else if (node->left) {
                node = rotate_left_right(node); // LR-type
            }
        } else if (node->bf > 1) { // 右子树过高
            if (node->right && node->right->bf >= 0) {
                node = rotate_left(node); // RR-type
            } else if (node->right) {
                node = rotate_right_left(node); // RL-type
            }
        }
        // 向上更新父节点
        if (!node->parent) {
            this->root = node; // 更新root
        }
        node = node->parent;
    }
}

// 插入操作
bool AVLTree::insert(int key) {
    if (!this->root) {
        this->root = new Node(key);
        return;
    }
    AVLNode node = new Node(key), curr = this->root, p = nullptr;
    // 找到插入位置
    while (curr) {
        p = curr;
        if (key < curr->key) {
            curr = curr->left;
        } else if (key > curr->key) {
            curr = curr->right;
        } else {
            // 已经存在相同key，不插入
            return false;
        }
    }

    // 创建新节点
    AVLNode new_node = new Node(key);
    new_node->parent = p;
    if (key < p->key) {
        p->left = new_node;
    } else {
        p->right = new_node;
    }
    // 插入后沿父节点向上更新balance factor
    re_BF(new_node);
    return true;
}

        return ;
    }

    queue<AVLNode> q;
    q.push(this->root);

    while (!q.empty()) {
        AVLNode curr = q.front();
        q.pop();
        arr.push_back(curr->key);
        if (curr->left != nullptr) {
            q.push(curr->left);
        }
        if (curr->right != nullptr) {
            q.push(curr->right);
        }
    }

    return arr;
}

#include <stack>
#include "AVLTree.h"
#define _left 0 // 下一步访问左子树
#define _right 1 // 下一步访问右子树
#define _leave 2 // 下一步弹出

// 利用双栈实现：中序遍历
vector<int> AVLTree::traversal_in_s() {
        vector<int> arr;
        AVLNode curr;
        stack<AVLNode> s_node;
        stack<char> s_op;
        s_node.push(this->root);
        s_op.push(_left);
        while (!s_node.empty()) {
                curr = s_node.top();
                // 查看下一步的操作
                char op = s_op.top();
                s_op.pop();
                switch (op) {
                        case _left:
                        s_op.push(_right); // 当前节点下一步要访问右子树
                        if (curr->left != nullptr) { // 下一个要访问的节点 是 左子树
                                s_node.push(curr->left);
                                s_op.push(_left); // 当前节点的左子树下一步 要 访问 左子树
                            }
                        break;
                        case _right:
                        arr.push_back(curr->key); // 因为是先序遍历直接做这个操作就行了
                        s_op.push(_leave); // 当前节点下一步应该被弹出
                        if (curr->right != nullptr) { // 下一个要访问的节点 是 右子树
                                s_node.push(curr->right);
                                s_op.push(_left);
                            }
                        break;
                        case _leave:
                        s_node.pop(); // 弹出
                        break;
                    }
            }
        return arr;
    }
